# Delivery checklist

- [x] Responsive appointment dashboard for viewing upcoming, past, and current appointments across desktop and mobile devices.
- [x] Appointment creation form with service, staff member, customer details, date, time, status, and notes.
- [x] Appointment status updates using pending, confirmed, completed, canceled, and no-show states.
- [x] Appointment rescheduling by editing date, time, service, or assigned staff while preserving the appointment ID.
- [x] Appointment cancellation with confirmation and persisted canceled status.
- [x] Basic service management for viewing, creating, editing, and deactivating service records.
- [x] Basic staff management for viewing, creating, editing, and deactivating staff records.
- [x] Google Sheets schema and Google Apps Script API with validation and CRUD operations.
- [x] Vercel frontend integration with loading, form states, error handling, success feedback, and demo fallback.
- [x] GitHub, Google Sheets, Apps Script deployment, and Vercel configuration instructions.
- [ ] User must paste `appsscript/Code.gs` into Apps Script, run `setup()`, and deploy the Web App.
- [ ] User must add `APPS_SCRIPT_URL` and optional `APPS_SCRIPT_API_KEY` in Vercel.
